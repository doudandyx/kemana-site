# Kemana — site

Site de [kemana.co](https://kemana.co), publié avec GitHub Pages depuis la branche `main`.

- `index.html` : la page unique (anglais par défaut, français par le bouton EN / FR).
- `site.css` : les styles. Toutes les couleurs sont des jetons en haut du fichier ; le thème sombre ne fait que les redéfinir.
- `site.js` : la langue, le thème et l'afficheur à points de l'ouverture.
- `fonts/` : Inter et JetBrains Mono (licence OFL), servies par le site. Aucun appel à Google Fonts, aucun cookie, aucun traceur.
- `CNAME` : le nom de domaine.

Pour voir le site en local : `python3 -m http.server 8792` dans ce dossier, puis http://localhost:8792.
